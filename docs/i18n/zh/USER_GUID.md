# 📖 DiscountCards 用户指南

欢迎使用 **DiscountCards** —— 您可靠、快速且完全离线的会员卡卡包。本指南将帮助您设置应用、添加卡片并以最高效率使用它们。

---

## 📥 第 1 章：安装与首次启动

1. **下载**：前往 [GitHub Releases](https://github.com/Storvild/android_discount_cards/releases) 页面，下载最新的 `.apk` 文件（例如 `discount_cards_v1.1 7.apk`）。
2. **安装**：打开下载的文件。如果系统提示权限请求，请在 Android 设置中允许从此来源（浏览器或文件管理器）安装应用。
3. **首次启动**：应用会即刻打开。它不需要注册、创建账户或访问互联网。
4. **权限**：当首次尝试使用相机扫描卡片时，应用会请求 **相机** 权限。此权限是可选的：如果您计划手动或从图库添加卡片，可以拒绝该权限。

---

## ➕ 第 2 章：添加新卡片

点击主屏幕上的浮动 **“+”** 按钮。也可以点击菜单中的“添加卡片...”。您可以使用三种添加方式（点击代码字段旁边的相应图标）：

### 方式 A：相机扫描（推荐）
1. 将手机相机对准实体卡片。
2. 应用将通过 ML Kit 自动识别条形码或二维码。
3. 检查识别出的号码并点击“保存”。

### 方式 B：从文件 / 图库选择
1. 如果图库中已有条形码照片，请选择此选项。
2. 指定图像，应用将从中提取数据。

### 方式 C：手动输入
1. 输入 **商店名称**（例如“沃尔玛”）。
2. 输入 **卡号**（手动输入或粘贴）。
3. 从列表中选择 **代码类型**（例如大多数超市卡选择 `EAN_13`，二维码选择 `QR_CODE`，或者仅凭手机号即可享受折扣时选择 `PHONE`）。
4. *（可选）* 添加备注或 CVC/CVV 代码。
5. 点击“保存”。

### 🚀 快速与批量添加卡片
- **相机批量扫描：** 在主屏幕下拉菜单（"..."）中选择 **工具 → 批量扫描…**。相机将以连续扫描模式打开。
- **从图片批量添加：** 在菜单中选择 **工具 → 从图片批量添加…**。从图库中选择多张图片。

---

## 🛒 第 3 章：在收银台使用卡片

应用提供了几种便捷的方式出示卡片，无需在菜单中翻找：

### 1. 主要方式
- 打开所需的卡片（必要时使用搜索功能）。
- 在收银台出示条形码。

### 2. 全屏模式（遇到扫码困难时）
- 打开所需的卡片。
- **直接点击条形码图像**。
- 它将展开至全屏：背景变为白色，屏幕亮度自动提升至 100%，且在竖屏方向下条形码会旋转 90°，以便收银员扫描器完美识别。

### 3. 主屏幕小组件
- 打开已放置条形码小组件的屏幕，在收银台出示。
- 如何添加小组件请参见第 8 章。

### 4. 发送条形码（分享），如果您想让其他人出示卡片
- 在卡片详情屏幕上点击 **“分享条形码图片”** 按钮。
- 选择应用或社交软件。图像将以带白色边框的 PNG 格式发送，确保接收者能够成功扫描。

## 🗂️ 第 4 章：卡片管理与组织

当卡片较多时，组织工具可以提供帮助：

- **搜索**：使用主屏幕顶部的搜索栏。搜索支持按商店名称、卡号和备注进行查找。
- **排序**：点击排序图标，按名称、创建日期或使用频率对卡片进行排序。
- **收藏**：点击卡片上的星号 ⭐️ 图标，将常用卡片移至列表顶部。
- **上下文菜单**：在列表中的任意卡片上 **长按**，可快速调出“编辑”或“删除”菜单。
- **归档**：如果卡片已过期但舍不得删除，请打开其详情并点击“移入归档”。归档卡片会从主列表、搜索和导出中隐藏，但随时可以通过“归档”菜单恢复。

## 🎨 第 5 章：外观自定义

前往 **设置**（齿轮图标）以个性化应用：

- **主题**：选择浅色、深色或跟随系统主题。
- **紧凑列表模式**：启用此选项可隐藏主屏幕上的条形码和卡号。这会将卡片高度缩减一半，并显著加快在所有设备上的滚动速度。
- **卡片内显示亮度调节**：直接在卡片屏幕上启用亮度滑块，以便在扫描前进行快速手动调整。
- **界面语言**：无视系统语言，独立选择 11 种支持语言中的一种。

*在编辑单个卡片时，您还可以通过调色板或 HEX 代码（例如 `#0EE8A5`）为其设置独特的颜色和类别图标。*

## 💾 第 6 章：备份与数据迁移

您的数据完全属于您自己。请定期创建备份。

### 导出（创建副本）
1. 前往菜单（"..."） → **工具 → 导出到文件…**。
2. 选择格式：
   - **JSON**：包含所有细节（颜色、图标、日期、CVC、归档状态）的完整格式。推荐用于迁移到其他设备。
   - **CSV**：表格格式（名称、代码、代码类型、CVC、备注）。方便在 Excel 中查看。
3. 将文件保存到方便的文件夹中，或直接通过社交软件/云盘发送给自己。

### 导入（恢复副本）
1. **自动方式**：在文件管理器中找到保存的 `.json` 或 `.csv` 文件并点击它。选择“打开方式” → **DiscountCards**。应用将自动启动导入流程。
2. **手动方式**：前往菜单（"..."） → **工具 → 从文件导入…** 并手动选择文件。
3. **选择导入模式**：
   - **合并（MERGE）**：将新卡片添加到现有卡片中（推荐）。
   - **覆盖（OVERWRITE）**：完全删除当前卡片并用文件中的数据替换。
4. **检测到重复项时**，应用将提供处理策略：更新现有卡片、作为新卡片添加或跳过。

## ⚠️ 第 7 章：常见问题解决

| 问题 | 解决方案 |
| :--- | :--- |
| **收银台扫描器无法识别屏幕上的条形码** | 1. 点击条形码进入全屏模式（最大亮度 + 白色背景）。<br>2. 确保在创建卡片时正确选择了代码类型（通常为 `EAN_13` 或 `CODE_128`）。<br>3. 擦拭屏幕上的指纹。 |
| **相机无法聚焦在实体卡片上** | 确保良好的照明。如果相机无法正常工作，请使用手机的标准相机拍照，然后使用 DiscountCards 中的“从文件选择”功能。 |
| **卡片较多时应用显得卡顿** | 前往设置并开启 **“紧凑列表模式”**。这将关闭总列表中条形码的渲染，使运行速度提高数倍。 |
| **找不到导入的文件** | 请确保您下载的文件格式为 `.json` 或 `.csv`。导入时应用会自动识别 CSV 中的分隔符（逗号、分号或制表符）。 |

## 第 8 章：🧩 主屏幕小组件

**如何在手机主屏幕上添加小组件？**  
1. 用手指长按智能手机主屏幕上的任意空白区域。  
2. 在出现的底部菜单中选择 **“小组件”** (Widgets)。  
3. 浏览应用列表并找到 **DiscountCards**。  
4. 长按小组件图标，不要松开手指，将其拖动到屏幕上的空白位置。  
5. 放置后会立即打开设置窗口：从列表中选择所需的折扣卡，然后点击“完成”（或“保存”）。
6. 在小组件设置中有预览功能，展示不同尺寸下小组件的大致样子（实际显示取决于手机型号）。实际小组件尺寸本身不会发生变化。此外，设置中还可以指定是否显示名称和条形码。

**如何更改已选卡片或小组件设置？**  
您有两种方便的方法：  
- **通过小组件本身：** 点击小组件右上角的半透明编辑按钮。这将打开一个菜单，可以在其中选择其他卡片或更改显示参数。  
- **通过 Android 菜单：** 用手指长按已放置的小组件。在弹出的菜单中点击 **“小组件设置”**（此功能并非在所有手机上都有效）。

**如何调整小组件尺寸？**  
DiscountCards 小组件具备自适应能力，支持 **1×1 到 5×5** 网格大小。要调整其尺寸：  
1. 长按主屏幕上的小组件。  
2. 选中后，其边缘会出现拉伸标记（通常为蓝色或对比鲜明的点/条）。  
3. 向所需方向拖动这些标记以增大或缩小小组件区域。  
4. 松开手指以固定新尺寸。  
💡 *提示：* 在最小尺寸（1×1）下，仅显示紧凑图标或迷你条形码。若要放大条形码，可以在设置中取消显示名称。为了在收银台方便扫描，建议使用 **2×2** 或更大的尺寸，以便能看清商店名称和完整的条形码。
