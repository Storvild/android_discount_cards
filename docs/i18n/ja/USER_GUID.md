# 📖 DiscountCards ユーザーガイド

**DiscountCards** へようこそ — 信頼性が高く、高速で完全オフラインのポイントカード保管庫です。このガイドでは、アプリの設定、カードの追加、アンド最大限の効率での活用方法について説明します。

---

## 📥 第1章: インストールと初回起動

1. **ダウンロード**: [GitHub Releases](https://github.com/Storvild/android_discount_cards/releases) ページにアクセスし、拡張子が `.apk` の最新ファイルをダウンロードします（例: `discount_cards_v1.1 7.apk`）。
2. **インストール**: ダウンロードしたファイルを開きます。システムから許可を求められた場合は、Android の設定でこのソース（ブラウザまたはファイルマネージャー）からのアプリのインストールを許可してください。
3. **初回起動**: アプリは瞬時に開きます。登録、アカウント作成、インターネット接続は一切不要です。
4. **権限**: カメラで初めてカードをスキャンしようとすると、アプリは **カメラ** へのアクセス権限をリクエストします。この権限は任意です。手動またはギャラリーからカードを追加する予定の場合は拒否しても構いません。

---

## ➕ 第2章: 新しいカードの追加

メイン画面のフローティング **「+」** ボタンをタップします。また、メニューの「カードを追加...」をタップすることもできます。3つの追加方法を利用できます（コードフィールドの横にある対応するアイコンをタップします）:

### 方法 A: カメラでのスキャン（推奨）
1. スマホのカメラを実物のカードに向けます。
2. アプリは ML Kit を使用してバーコードまたは QR コードを自動的に認識します。
3. 認識された番号を確認し、「保存」をタップします。

### 方法 B: ファイル / ギャラリーからの選択
1. ギャラリーにすでにバーコードの写真がある場合は、このオプションを選択します。
2. 画像を指定すると、アプリがそこからデータを抽出します。

### 方法 C: 手動入力
1. **店舗名** を入力します（例: 「セブン-イレブン」）。
2. **カード番号** を入力します（手動入力または貼り付け）。
3. リストから **コードの種類** を選択します（例: 多くの食品スーパーカードでは `EAN_13`、QR コードは `QR_CODE`、電話番号のみで割引が適用される場合は `PHONE`）。
4. *（任意）* メモや CVC/CVV コードを追加します。
5. 「保存」をタップします。

## 🛒 第3章: レジでのカードの使用

アプリは、メニューを探し回ることなくカードを提示するための便利な方法をいくつか提供しています:

### 1. 基本的な方法
- 必要なカードを開きます（必要に応じて検索を使用してください）。
- レジでバーコードを提示します。

### 2. 全画面モード（読み取りが困難な場合）
- 必要なカードを開きます。
- **バーコード画像自体をタップします**。
- 全画面に拡大表示されます: 背景が白になり、画面の明るさが自動的に100%まで上がり、縦画面向きの場合は店員のレジスキャナーで理想的に読み取れるようバーコードが90°回転します。

### 3. ホーム画面のウィジェット
- バーコード付きウィジェットを配置した画面を開き、レジで提示します。
- ウィジェットの追加方法については第8章を参照してください。

### 4. バーコードの送信（共有）他の人にレジでカードを提示してもらいたい場合
- カード詳細画面で **「バーコード画像を共有」** ボタンをタップします。
- メッセージアプリまたは共有先アプリを選択します。画像は白枠付きの PNG 形式で送信されるため、受取人が確実にスキャンできます。

## 🗂️ 第4章: カードの管理と整理

カードが増えてきたら、整理ツールが役に立ちます:

- **検索**: メイン画面上部の検索バーを使用します。店舗名、カード番号、メモから検索できます。
- **ソート**: ソートアイコンをタップして、名前、作成日、または使用頻度でカードを並べ替えます。
- **お気に入り**: カードの星 ⭐️ アイコンをタップすると、よく使うカードをリストの先頭に固定できます。
- **コンテキストメニュー**: リスト内の任意のカードを **長押し** すると、「編集」または「削除」メニューを素早く呼び出せます。
- **アーカイブ**: カードが古くなったけれど削除したくない場合は、詳細を開いて「アーカイブに移動」をタップします。アーカイブされたカードはメインリスト、検索、エクスポートから非表示になりますが、「アーカイブ」メニューからいつでも復元できます。

---

## 🎨 第5章: 外観のカスタマイズ

アプリをパーソナライズするには **設定**（歯車アイコン）に移動します:

- **デザインテーマ**: ライト、ダーク、またはシステムテーマを選択します。
- **コンパクトリストモード**: このオプションを有効にすると、メイン画面のバーコードとカード番号が非表示になります。これによりカードの高さが半分になり、すべての端末でスクロール速度が大幅に向上します。
- **カード内輝度調節**: スキャン前にすばやく手動調整できるよう、カード画面上に直接明るさスライダーを表示します。
- **UI言語**: システムの言語に関係なく、対応する11言語から1つを選択できます。

*個別のカードを編集する際、パレットまたは HEX コード（例: `#0EE8A5`）およびカテゴリアイコンを使用して、固有の色を設定することもできます。*

## 💾 第6章: バックアップとデータ移行

あなたのデータはあなただけのものです。定期的にバックアップを作成してください。

### エクスポート（バックアップの作成）
1. 設定 → **エクスポート** に移動します。
2. 形式を選択します:
   - **JSON**: すべての詳細（色、アイコン、日付、CVC、アーカイブ状態）を含む完全な形式。別の端末への移行に推奨されます。
   - **CSV**: テーブル形式（名前、コード、コードの種類、CVC、メモ）。Excel での表示に便利です。
3. ファイルを都合の良いフォルダに保存するか、メッセージアプリ/クラウドにすぐに送信します。

### インポート（バックアップの復元）
1. **自動方法**: ファイルマネージャーで保存した `.json` または `.csv` ファイルを見つけてタップします。「アプリを選択して開く」 → **DiscountCards** を選択します。アプリが自動的にインポート処理を開始します。
2. **手動方法**: 設定 → **インポート** に移動し、手動でファイルを選択します。
3. **インポートモードを選択します**:
   - **マージ (MERGE)**: 新しいカードを既存のカードに追加します（推奨）。
   - **上書き (OVERWRITE)**: 現在のカードを完全に削除し、ファイルのデータに置き換えます。
4. **重複が検出された場合**、アプリは処理戦略を提案します: 既存を更新、新規として追加、またはスキップ。

## ⚠️ 第7章: よくある問題の解決

| 問題 | 解決策 |
| :--- | :--- |
| **レジで画面のバーコードが読み取れない** | 1. バーコードをタップして全画面モードにします（最大輝度 + 白背景）。<br>2. カード作成時にコードの種類が正しく選択されているか確認します（通常は `EAN_13` または `CODE_128`）。<br>3. 画面の指紋を拭き取ります。 |
| **カメラが実物のカードにピントが合わない** | 十分な照明を確保してください。カメラでうまく撮影できない場合は、スマホの標準カメラでカードを撮影し、DiscountCards の「ファイルから選択」機能を使用してください。 |
| **カードの枚数が多いとアプリが重く感じる** | 設定に移動し、**「コンパクトリストモード」** を有効にします。これにより全体リストでのバーコード描画がオフになり、動作速度が大幅に向上します。 |
| **インポートしたファイルが見つからない** | `.json` または `.csv` 形式のファイルをダウンロードしたことを確認してください。インポート時、アプリは CSV 内の区切り文字（カンマ、セミコロン、タブ）を自動的に認識します。 |

## 第8章: 🧩 ホーム画面のウィジェット

**スマホのホーム画面にウィジェットを追加するにはどうすればよいですか？**  
1. スマートフォンのホーム画面の空いている場所を長押しします。  
2. 表示された下部メニューで **「ウィジェット」** (Widgets) を選択します。  
3. アプリのリストをスクロールし、**DiscountCards**（または「ディスカウントカード」）を見つけます。  
4. ウィジェットのアイコンを長押しし、指を離さずに画面の空いている場所にドラッグします。  
5. 配置直後に設定ウィンドウが開きます。リストから必要なディスカウントカードを選択し、「完了」（または「保存」）をタップします。
6. ウィジェット設定にはプレビュー機能があり、さまざまなサイズでウィジェットがどのように表示されるかの目安を確認できます（実際の表示はスマホの機種に依存します）。実際のウィジェットのサイズ自体は自動では変更されません。また設定で名称やバーコードを表示するかどうかを指定できます。

**選択したカードやウィジェットの設定を変更するにはどうすればよいですか？**  
2つの便利な方法があります:  
- **ウィジェット自体から:** ウィジェット本体の右上にある半透明の編集ボタンをタップします。これにより、別のカードを選択したり表示パラメーターを変更したりできるメニューが開きます。  
- **Android メニューから:** 配置済みのウィジェットを長押しします。表示されるポップアップメニューで **「ウィジェット設定」** をタップします（すべてのスマホで機能するわけではありません）。

**ウィジェットのサイズを変更するにはどうすればよいですか？**  
DiscountCards ウィジェットはレスポンシブに対応しており、**1×1 から 5×5** グリッドのサイズをサポートしています。サイズを変更するには:  
1. ホーム画面のウィジェットを長押しします。  
2. 選択状態になると、端にサイズ調整ハンドル（通常は青色または対比色の点/線）が表示されます。  
3. これらのハンドルを任意の方向に引っ張って、ウィジェットの領域を拡大または縮小します。  
4. 指を離して新しいサイズを固定します。  
💡 *ヒント:* 最小サイズ (1×1) では、コンパクトなアイコンまたはミニバーコードのみが表示されます。バーコードを大きくするには、設定で名称の表示をオフにします。レジでスムーズにスキャンできるようにするには、店舗名と完全なバーコードが見える **2×2** 以上のサイズを使用することをお勧めします。
