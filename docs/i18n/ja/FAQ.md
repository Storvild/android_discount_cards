# ❓ よくある質問 (FAQ) — DiscountCards

## 📌 概要

**DiscountCards とは何ですか？**  
ポイントカードやディスカウントカードを保存、スキャン、活用するための軽量で高速な Android アプリです。カードで膨らんだ実物の財布に取って代わり、スマートフォン画面からレジでバーコードを即座に提示できます。

**アプリは無料ですか？**  
はい、プロジェクトは完全に無料で、MIT ライセンスの下でオープンソース (Open Source) として配布されています。最新の APK バージョンは [GitHub Releases](https://github.com/Storvild/android_discount_cards/releases) セクションからダウンロードできます。

**アプリ内に広告やトラッカーはありますか？**  
いいえ。アプリは完全に自立して動作し、広告を含まず、アナリティクスやトラッキングトラッカーを一切使用していません。

**アプリはインターネットがなくても動作しますか？**  
はい、これは **完全オフラインアプリ** です。マニフェスト (Manifest) に `android.permission.INTERNET` 権限すら含まれていません。すべてのデータは端末上にのみ保存されるため、通信圏外のエリア（例: ハイパーマーケットの地下など）でも確実に動作します。

---

## 🔒 セキュリティとプライバシー

**私のデータはどこに保存されますか？**  
すべてのデータ（カード、設定、統計）は端末のデータベース内にローカル保存されます。サードパーティのサーバーに情報が送信されることは一切ありません。

**アプリはどのような権限をリクエストしますか？**  
アプリが必要とする権限は1つだけで、それも **使用する瞬間のみ** リクエストされます:
- `android.permission.CAMERA` — カメラ経由で実物のカードをスキャンするためだけに必要です。手動またはギャラリーからカードを追加する場合は、この権限は不要です。

## 💳 使用方法と機能

**新しいカードを追加するにはどうすればよいですか？**  
3つの方法があります:
1. **手動:** 店舗名、カード番号を入力し、バーコードの形式を選択します。
2. **スキャン:** 「カード番号」セクションの QR コードアイコン付きボタンをタップし、カメラを実物のカードに向けます（高速認識に ML Kit を使用）。
3. **ファイルから:** 「カード番号」セクションのボタンをタップし、ギャラリーまたはファイルマネージャーから保存したバーコード画像を選択します。

**対応しているバーコードの形式は何ですか？**  
アプリは以下を生成および認識します: `QR_CODE`、`CODE_128`、`EAN_13`、`EAN_8`、`UPC_A`、`CODE_39`、`PDF_417`、`AZTEC`。また、電話番号のみで割引が適用されるカード用の `PHONE` モードもあります（バーコードは生成されず、大きなテキストとして表示されます）。

**バーコードの読み取りが悪い場合はどうすればよいですか？ レジで店員がバーコードを簡単に読み取れるようにするには？**  
- カード内のバーコードをタップします: 最大輝度、白背景、自動で90°回転（縦画面向き時）する **全画面モード** で開き、理想的にスキャンできます。
- 設定で「カードに輝度を表示」を有効にすると、カード画面上で直接スライダーを使って明るさを調整できます。
- また、**「バーコード画像を共有」** ボタンをタップして、白枠付きの PNG バーコード画像をメッセージアプリで送信することもできます（例: 配送業者や知人を介して購入する場合など）。

**低スペックの端末でアプリの動作を速くするにはどうすればよいですか？**  
設定で **「コンパクトリストモード」** を有効にします。これによりメイン画面でのバーコードとカード番号の描画がオフになり、リスト項目の高さが半分になり、読み込みとスクロールが大幅に高速化します。

**カードにメモや CVC コードを追加できますか？**  
はい、カードの編集時に任意のメモや CVC/CVV コードフィールドを追加できます（例: ポイントを利用する場合など）。

## 💾 バックアップとデータ移行

**カードのバックアップを作成するにはどうすればよいですか？**  
設定 → エクスポート に移動します。すべてのデータを **JSON**（完全なデータ構造、推奨）または **CSV**（Excel での表示に便利なテーブル）形式で保存できます。

**新しいスマホにカードを移行するにはどうすればよいですか？**  
1. 古い端末でカードをファイル（JSON または CSV）にエクスポートします。
2. そのファイルを新しい端末に転送します（Bluetooth、メッセージアプリ、クラウド、USB経由など）。
3. 新しい端末でファイルマネージャーを介してファイルを開きます。アプリが自動的に操作を検出し、カードのインポートを提案します。

**インポートモードの違いは何ですか？**  
- **マージ (MERGE):** ファイル内のカードをアプリ内の既存のカードに追加します。
- **上書き (OVERWRITE):** 現在のカードをすべて完全に削除し、ファイルのデータに置き換えます。
- *カードが重複する場合*（番号と名称による）、既存を更新、新規重複として追加、またはスキップから戦略を選択できます。

## 🧩 ウィジェットと整理

**アプリを開かずにカードを表示できますか？**  
はい。ホーム画面に DiscountCards ウィジェットを追加します。1×1 から 5×5 までのサイズに対応しており、バーコードと店舗名を表示し、タップすると即座にカード全体を開きます。

**カードが増えすぎた場合に整理するにはどうすればよいですか？**  
- よく使うカードには **お気に入り**（⭐️）を使用して、リストの上位に表示させます。
- **アーカイブ** を使用します: 使わなくなったカードや期限切れのカードをアーカイブに移動します。メインリスト、検索、エクスポートから消えますが、永久に削除されるわけではありません。いつでも復元できます。
- カードがもう必要ないと確信している場合は、削除してください。

**カードの外観をカスタマイズできますか？**  
はい。各カードについて、カテゴリアイコンやパレットからの色選択、または正確な HEX コード (`#RRGGBB`) を設定できます。また、ライト、ダーク、システムの各デザインテーマに対応しています。

## 🛠 トラブルシューティング

**レジのスキャナーが私の画面からバーコードを読み取りません。どうすればよいですか？**  
1. カード作成時に **バーコード形式** が正しく選択されているか確認してください（例: 多くの食品スーパーカードでは `EAN_13`）。
2. 100%の明るさと白背景を確保するため、バーコードの全画面モード（カード上のバーコードをタップ）を使用してください。
3. 画面の指紋や皮脂汚れを拭き取ってください。

**アプリがカメラで実物のカードをスキャンできません。**  
- アプリにカメラへのアクセスを許可していることを確認してください（スキャンボタンを初めてタップしたときにリクエストされます）。
- 十分な照明を確保し、10〜20 cm 離れた場所からカメラをバーコードに対して平行に保持してください。
- バーコードが損傷しているかカメラで処理できない場合は、スマホの標準カメラで写真を撮影した上で **「ファイルから選択」** 機能を使用してください。

**アプリの言語を変更するにはどうすればよいですか？**  
アプリの設定に個別の「言語」項目があります。スマートフォンのシステム言語に関係なく、対応している 11 言語（Русский、English、Deutsch、Français、Español、Português、日本語、简体中文、العربية、Türkçe、हिन्दी）から 1 つを選択できます。
